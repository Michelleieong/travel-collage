# Travel Collage

This project is a personal travel journal documenting three cities I have traveled to: Antwerp, Paris, and Cusco.

Each page explores a different part of my travel memories through photographs, text, typography, and different CSS Grid layouts. I wanted the website to feel more like a personal journal or scrapbook rather than a traditional travel website.

- Antwerp: an avant-garde visual journal of my memories, outfits, food, museums, and places.
- Paris: a romantic travel diary documenting everyday moments, food, and what I wore.
- Cusco: a travel journal about adventure, from Cusco to Aguas Calientes and Machu Picchu.

The website was created using HTML and CSS, with CSS Grid for the layouts. I used Google Fonts for the typography and VS Code to write and edit the code.

All photographs and videos used in this project are from my personal travel archive.
